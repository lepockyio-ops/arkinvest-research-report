# 第二部分：调查与证据规范

本文件均为可执行的规范建议；除非有原文证据，不将步骤归因于参考报告作者。

## 9. 界定问题

填写任务卡，至少包括：核心问题、研究单位、地域与司法辖区、分析时点及时区、统计期间、预测期、比较对象、排除范围、初始假设、替代解释和证据门槛。

比较对象依据商业模式、风险暴露、客户、地域或生命周期选择，不能只选支持结论的赢家。说明共同点与不可比处。把“最近一季”写成具体季度，并区分已发布完整财报、部分经营更新和估算。

历史时点研究不得悄悄引入之后发布的资料；如增加事后验证，单列并注明它不属于当时信息集。

## 10. 优先查找的一手来源

一手身份按证据的原始生产者和用途判定，不按转载网站判定。公司自己的预测是一手管理层说法，不是已实现结果。

| 主张 | 优先证据 | 仍需注意 |
|---|---|---|
| 收入、利润、现金流、债务与融资条款 | 监管申报、经审计报表、附注、合同、招股文件 | 合并范围、到期/回售/赎回、担保、稀释和期后事项 |
| 法律、牌照、诉讼和监管 | 法条、主管机关文件、判决、案件卷宗 | 草案/生效、适用地域、上诉与执行状态 |
| 技术能力、安全和标准 | 论文、标准原文、版本化代码、测试与事故报告 | 理论/实验/生产、测试条件、作者与利益关系 |
| 市场规模和宏观数据 | 官方统计、原始调查、定义透明的行业数据库 | 样本覆盖、分母、修订与未观测范围 |
| 产品需求与单位经济 | 实际付费、留存、合同、采购与客户调查 | 补贴、关联方、重复用户、转售与选择性披露 |
| 数字资产、托管与抵押 | 链上记录、法律文件、托管协议、审计或鉴证 | 地址归属、负债与资产是否对应、法律追索、鉴证范围 |
| 管理层判断与承诺 | 原始电话会、公告、录音或逐字稿 | 说话日期、原文上下文、是否后来修改或兑现 |

## 11. 选择数据库、访谈和第三方研究

- **数据库：** 记录覆盖范围、采集方法、去重、更新频率、修订、可下载性和商业限制。无法取得底层数据时，不声称完成复算。
- **公司披露：** 对齐财年与自然年，读取附注、非 GAAP 调节表和历史重述；摘要幻灯片不能覆盖附注里的限制。
- **监管资料：** 记录管辖机关、文号、效力状态和发布日期；媒体解读不能替代原文的适用范围。
- **访谈：** 事先明确抽样、角色、利益关系和问题；区分可归因内容与匿名意见；不编造访谈。联系受访者或发送问题须有用户授权。听过公开播客，只能写公开访谈材料，不能写自己做过调研访谈。
- **第三方研究：** 查作者、资助、持仓或业务关系、方法和原始出处；引用估算时保留其估算属性。观点相同不代表来源独立。
- **付费与访问受限：** 可记录元数据和已见摘录，但不能假装读过全文；提供可行替代来源或取得数据的路径。

## 12. 数据台账

每个关键数字或证据记录以下字段；不适用写“不适用”，未披露写“未注明”，不要留空造成误解。

1. 证据 ID、对应主张、原始数值或原文概述、单位与币种。
2. 统计期间或时点、地域、研究单位、样本及分母。
3. 指标定义、GAAP/调整后、名义/实际、存量/流量、总额/净额、累计/期间等口径。
4. 发布日期、数据截止日、检索日期；三者不能互换。
5. 来源标题、原始生产者、URL、页码/章节/表号或链上区块定位。
6. 一手/二手/分析者估算分类、证据状态、是否可追溯、是否复算、是否独立验证。
7. 转换公式、汇率和基准日、调整后数值、局限、来源版本、独立核验来源 ID。

原始数值与加工结果同时保留。截图或缓存只能证明当时看到什么，不能替代来源权限与真实性核验。

## 13. 分开六类陈述

| 标签 | 使用条件 |
|---|---|
| 〔核实事实〕 | 有适当来源，可定位并说明核验范围的已发生事项；涉及财务可写“披露值”，不要暗示自己重新审计 |
| 〔管理层说法〕 | 计划、解释、预测、口径或自报能力；证实原话存在不等于证实其内容 |
| 〔第三方估算〕 | 媒体、数据库、研究者或其他机构的测算；保留方法、期间和限制 |
| 〔分析者估算〕 | 本次计算；必须给输入、公式、假设和误差来源 |
| 〔分析推断〕 | 从证据连接到机制或判断；说明可能的其他解释 |
| 〔未知／待核实〕 | 未找到、访问受限、无法对齐或证据冲突尚未解决 |

报告明确写出、研究者从文本归纳、文本无法确认，是另一条独立维度。审阅他人报告时也记录这一维度，不能用自己的推断补成作者事实。

## 14. 重要主张的独立核验

重要主张指：换成合理的另一个数值或机制，就会改变方向、量级、情景权重或风险结论。

1. 找到原始出处，核对日期、定义和上下文。
2. 寻找独立生成或独立验证同一主张的证据链。新闻转载、同一数据供应商的多个图表、同一公司的公告与电话会，不能计作多个独立事实来源。
3. 先对齐口径，再做算术、加总、比例及数量级检查；无法对齐时只比较可比部分。
4. 分别记录“出处可追溯”“算术已复算”“独立已验证”。找到脚注只满足第一项。
5. 法律条款或合同可能只有唯一权威原文；应精确定位条款，并争取独立解释或实践验证。不要为满足数量要求伪造第二个原始事实。
6. 只有单一来源时保留单一来源标签，下调信心或收窄结论。跨资料支持不同环节，不等于对同一数字做了交叉验证。

## 15. 来源不一致

依次检查：时间/时区、财年、样本、地域、单位/币种、毛额净额、存量流量、累计年化、会计口径、修订、归属和重复计算。

- 同表保留原始值、来源、差异原因、可比调整值与公式。
- 若较新数据属于明确修订，正文采用修订值并保留修订轨迹；不能仅因数字更新就假定定义不变。
- 原因未明时写“差异未解释”，分别用两种口径检查结论敏感性。不得无依据平均、挑选有利值或替管理层圆话。
- 引用原报告的计算错误时区分原值、复算值和影响，不悄悄改成正确数字后当作原作者结果。

## 16. 防止因果跳跃

检查时间先后、共同驱动因素、反向因果、选择偏差和对照条件。只有相关证据就写相关，不写导致；使用类推时列可比机制和失效条件。

逐段核对：**技术可行 → 可稳定部署 → 用户采用 → 愿意付费 → 正向单位经济 → 公司现金流 → 股东或代币价值**。每个箭头都需要证据，不能拿前端活动指标替代末端利润。

不要把融资额、资本开支、代币价格、社交热度或总交易量单独当成终端需求与盈利的证据。要区分付费需求、内部交易、补贴、循环采购、转售和公允价值变动。

## 17. 寻找反方与检查偏差

- 在最终判断前，专门检索至少一个失败或退出案例、一个利益立场不同的来源和一个能解释同一数据的竞争机制；查不到就记缺口。
- 记录最强反方如何改变判断，以及哪条证据最可能区分两种解释。不要只找容易驳倒的观点。
- 检查幸存者、便利抽样、时间窗口、未完成周期、补贴、披露、发表和前视偏差。
- 交易地址不等于用户，下载不等于活跃，活跃不等于付费，销量不等于利润；对每个替代指标说明映射误差。
- 对缺失值和样本剔除给规则；不在看过结果后选择窗口。无法避免的偏差要写明影响方向。

## 18. 模型与情景

- 披露输入、输出、公式、单位、校准依据、参数范围、依赖关系、产能/资金/法规约束、模型版本与运行方式。
- 将需求、价格、利用率、成本、投资、融资、稀释与现金流闭合。市场规模不自动等于可获得收入，收入不自动等于利润。
- 对最影响结论的参数做敏感性分析；写明哪些组合在现实中不能同时出现。不能默认所有输入独立。
- 概率须有基准率、样本或明确的分析判断依据。主观情景权重标为主观；缺少校准时使用范围或排序，不编造小数概率。
- 蒙特卡洛结果依赖输入分布和相关性；敏感性不是概率。各行各取分位数未必构成一张联合可实现的财务报表。
- 悲观情景应检查失败、融资窗口关闭、负债到期和稀释，而非仅取较低增长率。
- 规模测算注明交易量/收入/资产规模/估值，存量/年流量，总潜在/可服务/可获得范围及采用期限，防止重复加总。
- 文件可下载、公式可检查、结果已复算、经济解释已验证分别说明。没有运行就不写“已验证模型”。

## 19. 验证指标与证伪条件

为主要判断合计选择 3–5 个有区分力的指标，每个记录：

| 字段 | 要求 |
|---|---|
| 基线和定义 | 当前数值、日期、公式、单位、口径和来源 |
| 支持条件 | 什么阈值或范围、持续多久会支持判断 |
| 证伪条件 | 什么阈值、期限或机制变化会推翻或显著削弱判断 |
| 依据 | 阈值源自合同、盈亏平衡、历史样本、同业还是分析判断 |
| 追踪计划 | 下一次可获得日期、频率、来源、数据延迟和判断调整方式 |

支持与证伪不能都写成模糊的“持续改善/恶化”。阈值无法可靠设定时，写待定原因及待取得数据，不虚构数字。价格上涨、融资成功、社交热度不能单独验证盈利判断。

无结果也可能是证据；达到期限后按原标准评估，不悄悄延长期限。用户未要求持续监控时只交付追踪计划，不自动创建定时任务。

## 20. 缺口与最终检查

缺口按“未披露、访问受限、来源冲突、口径不可比、尚未验证、不可直接观测”分类，列取得路径、替代证据和对结论的影响。确认真做过检索后才写“未查到”；仅未开展检索写“尚未检索”。

交付前逐项检查：

- 核心问题、分析时点、数据截止日、统计期间与预测期是否清楚？
- 所有关键数值能否定位来源和日期，表格与正文是否一致？
- 一手、二手、管理层说法和本次推断是否分开？
- 引用是否直接支持旁边的主张，而非只有相关主题？
- 单位、分母、口径、加总、四舍五入和增长率是否自洽？
- 矛盾是否保留，最强反方是否被实质处理，风险是否进入方法？
- 不确定性是否影响结论范围、信心和情景，而非只出现在免责声明？
- 证伪指标是否可观察、有期限、有阈值依据？
- 模型运行、访谈、代码审计、链上归属或独立验证是否被过度声称？
- 数据缺口是否列清，是否按需要披露利益关系并附研究用途声明？

证据不足时缩小结论范围；无法确认时保留未知。完整报告不等于必须给出确定答案。
