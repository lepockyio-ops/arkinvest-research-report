# 第一部分：报告格式规范

## 标签与适用范围

【样本反复出现】仅指参考样本中多次可观察到的宏观结构，不表示每篇都使用，更不表示该机构或作者独有。

【规范建议】为提高可复核性新增的操作规则；除特别标注外，下文均属于这一类。不得把这些规则倒推成原作者实际做过的步骤。

## 1. 章节顺序与目的

用户指定格式优先。完整版默认采用下表；没有相关证据的部分可合并或写明不适用，不为凑章节补材料。

| 章节 | 目的 | 必须回答的问题 |
|---|---|---|
| 标题与基本信息 | 固定对象、时点与版本 | 研究谁？为何研究？截至何时？数据截止日是否一致？ |
| 一句话定性与摘要 | 先呈现判断及条件 | 主张是什么？最重要证据是什么？什么会推翻它？ |
| 问题与范围 | 划清研究边界 | 研究单位、地域、期间、比较对象与排除项是什么？ |
| 关键事实表 | 给出可核实的基础 | 哪些已知、哪些估算、哪些缺失？ |
| 机制与结构 | 解释变量如何传导 | 谁付钱、谁获利、谁承担风险？收入如何变成利润和现金？ |
| 数据分析与情景 | 展示从证据到判断的方法 | 用了何种比较、拆账或模型？约束、敏感性、失败路径是什么？ |
| 反方与风险 | 挑战主张 | 至少两个最强替代解释是什么？哪三个假设最脆弱？ |
| 条件式结论与追踪指标 | 明确判断期限和改变判断的条件 | 何时验证？什么阈值支持或推翻？ |
| 附录与数据缺口 | 让别人能够追溯和重做 | 原始来源、口径转换、计算、模型版本、冲突与未知在哪里？ |

公司研究应在机制分析中覆盖资本结构、生存能力、单位经济、行业竞争和估值；协议研究增加治理、托管与价值捕获；行业研究说明样本、边界和产业利润分配；技术研究区分能力、部署、可靠性和商业化。按问题选用，不机械套满所有镜片。

【样本反复出现】主题或结论导向标题；先说明主张或背景，再分节解释机制；用图表支持论述；以展望、限制或披露结束。上表的固定九章及顺序是规范建议。

## 2. 标题和小标题

- 主标题写研究对象和待回答的问题，或写带条件的核心判断；预测须标明终点年份。
- 小标题表达本节解决的问题或中间判断。使用“融资窗口关闭时现金能覆盖多久”等可回答的题目，避免“巨大机遇”“深度洞察”等空标题。
- 未验证的因果、必然结果或市场规模，不写成无条件事实。问题式标题不等于正文可以回避回答。
- 标题不模仿原作者独特措辞，不使用“新时代”“超级周期”等叙事替代证据。

## 3. 摘要

- 默认 3–5 句话：一句结论；一至两句关键证据和机制；一句最强反方或限制；一句验证条件。
- 全文选择 3–7 个决定结论的论据。摘要中每个关键数字都能追到事实表或来源。
- 区分结论、预测、建议与背景。管理层预测仍是管理层说法，不因出现在摘要而变成事实。
- 写清预测期限、情景条件和置信限制。模型第 25 百分位不能自动称为包含失败的“悲观情景”。

## 4. 正文的论述单元

采用“问题 → 证据 → 机制或方法 → 中间判断 → 局限与验证”顺序。事实与推断接近放置，但不能混为一句无法区分的话。

每段优先承担一个任务。默认每段 2–4 句；复杂推导可更长，先给中间结论并提供公式或附录。平行指标和比较用表格，连续推理用段落。

【样本反复出现】分节拆机制、穿插图表，再把局部结果连接到长期判断。固定的五步论述单元与段落长度是规范建议。

## 5. 图表和事实表

- 每张图回答一个明确问题，配一条可由图中数据支持的观察。不用图表制造证据充分的印象。
- 标明标题、单位、币种、分母、地域、统计期间、数据截止日、来源及必要调整。图表来源脚注不替代关键主张的具体出处。
- 实际值、估计值、预测值用图例区分。存量、流量、累计值、年化运行率不能放在一起暗示可比。
- 双轴、截断坐标、对数尺度、样本剔除、汇率和通胀调整须解释。
- 改绘注明原始来源和加工方法；从图形读数须标为近似。未做图表数字化，就不声称提取了精确原始数据。
- 事实表至少含“指标、数值、口径、期间或时点、来源及日期、证据类别、核验状态”。复杂字段放证据台账。

## 6. 反方和风险

至少列两个能解释同一证据的替代机制。反方应能改变判断，不能只写没有信息量的宏观风险清单。

每项风险写成：**触发条件 → 传导机制 → 受影响变量 → 可观察指标 → 判断或估值后果**。风险若决定结论，应进入情景、参数或约束；只写在免责段落不算处理。

资金成本、稀释、竞争、监管和执行失败不一定相互独立；说明共同触发因素。若无法可靠估计概率，给区间或定性排序并说明依据，不制造精确概率。

【样本反复出现】风险、未来判断的限制和利益披露。完整反方检验及风险入模是规范建议，不是对全部样本的描述。

## 7. 结论与附录

- 以“若 X，则 Y；除非 Z”给判断。说明 X、Z 对应哪些可观察变量。
- 需要时分短期（如 3–6 个月）和结构性（如 2–3 年），实际期限按题目调整。
- 明确相对与绝对、商业成功与股东或代币价值捕获之间的差别。价格下跌不自动证明基本面恶化，产品采用不自动证明盈利。
- 信心等级用高、中、低，理由指向来源质量、验证程度、样本和假设敏感性。不要把主观信心当统计概率。
- 附录依次放来源台账、指标定义与调整、计算与模型版本、来源冲突、数据缺口、重要利益关系。正文应能独立阅读，决定结论的限制不能藏在附录。

## 8. 语气、术语与归因

- 可核实事实用直接陈述；预测用条件和期限；推断说明依据；未知直接写未知。
- 首次出现术语给简短定义。单位经济、mNAV、运行率等指标必须写公式；不靠缩写体现专业性。
- 用短句、具体动词和可比较数字。避免无证据的褒贬、管理层吹捧、网络俚语与确定性买卖口号。
- 直接引用必须准确、简短、可定位；默认改用归因后的概述。不得生成某分析师“会说的话”。
- 将参考行业框架用于新领域时明确标为类推，说明对应变量与失效条件。不能冒称原作者研究过该领域。

【样本反复出现】专业术语、数据图表与长期展望交替。中性表述、条件式结论、词语克制和明确证伪是本技能的规范建议，不代表所有样本原有语气。
